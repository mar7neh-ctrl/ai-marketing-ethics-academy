# AI Marketing Ethics Academy

An interactive, remote-friendly Streamlit activity for **AI Policy, Ethics,
Governance, and Risk in Marketing Analytics**.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy free with Streamlit Community Cloud

1. Put this folder in a GitHub repository.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Select the repository and choose `ai_ethics_academy/streamlit_app.py` as the main file.
4. Click **Deploy** and share the generated link.

## Optional visual

The app works without external images. To replace the built-in fictional ad card
with a custom image, save a square PNG as:

`assets/risky_skincare_ad.png`

Recommended size: 1080 x 1080 px. Keep the fictional brand name **NovaGlow** and
include the intentionally risky phrases listed in `VISUALS_TO_CREATE.md`.

## Student evidence

Students can download a text completion report at any point. For the class
activity, ask them to submit the report or a screenshot of the Final Audit.
